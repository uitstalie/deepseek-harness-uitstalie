# @deepseek-ai/dsh-client-ui-models-dev

[English](README.md) | 中文

## 概述

`dsh-client-ui-models-dev` 给 Web 设置页加了一个分区：列出 models.dev 目录里的提供商，让你挑选并编辑它们的路由细节，然后把结果写成 `llm-plus` 路由。目录本身的拉取与缓存由 `dsh-models-dev` 负责；本包是它之上的浏览器界面，因此只要承载它的 host 服务与适配器已挂载，该分区就能工作。

<a id="use-this-package"></a>
## 使用本包

### 出现在哪里

该分区注册进设置界面，以提供商卡片的形式展示目录：每张卡给出提供商名、协议族、端点、凭据变量名与模型数量。搜索框可以缩小列表；目录里没有的提供商也可以手工添加。

### 你能做什么

选中一个提供商会打开该路由及其模型草稿表单：选择要暴露的模型、调整端点或协议，并标出哪些字段来自目录。保存即把选择落成适配器注册的路由，随后该分区会把它列在"我的路由"下，可以再编辑或删除。

### OAuth 提供商

需要交互式登录的提供商显示授权面板而不是单纯的密钥输入框：分区负责发起流程、显示进行中状态并报告结果，因此登录失败是可见的，而不是在后续请求里静默出错。

<a id="model-experience"></a>
## 模型体验

无：浏览器设置分区只编辑目录支撑的路由；注册并服务这些路由的 host 服务才拥有全部模型可见效果。

#### KV Cache 影响

无：该分区不贡献任何请求内容。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

这些限制说明该分区当前的范围。

- **只是设置界面**——它只列出与编辑路由，不测试路由、也不发探测请求。
- **列表由目录驱动**——没有挂载目录服务时列表为空，只剩手工录入。
- **路由形状跟随适配器**——表单编辑的正是 `dsh-llm-plus` 接受的字段，因此适配器新增字段需要这里同步新增表单字段。
